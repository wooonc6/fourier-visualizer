# 푸리에 변환 — 시각적 완전 해설

**🔗 [웹사이트 바로가기](https://wooonc6.github.io/fourier-visualizer/)**

3Blue1Brown의 "But what is the Fourier Transform?" 영상을 기반으로, 직접 손으로 조작하며 푸리에 변환을 이해할 수 있는 인터랙티브 학습 사이트입니다.

## 구성

| 섹션 | 내용 |
|------|------|
| 1. 왜 필요한가 | 사인파 합성기 — 여러 주파수를 섞고 복합 파형 확인 |
| 2. 3단계 접근법 | 핵심 아이디어 개요 |
| 3. 원에 감기 | 감기 주파수 슬라이더로 질량 중심 이동 체험 |
| 4. 주파수 스펙트럼 | 자동 스캔으로 스파이크 발생 확인 |
| 5. 공식 | 푸리에 변환 공식 및 오일러 공식 연결 |
| 6. 최종 정리 | 핵심 개념 요약 및 응용 분야 |

## 기술 스택

- HTML / CSS / JavaScript
- [P5.js](https://p5js.org/) — 인터랙티브 시각화
- [KaTeX](https://katex.org/) — 수식 렌더링
- GitHub Pages — 호스팅
