Fourier
Transform
복잡한 신호를 단순한 회전의 합으로 분해하는 수학적 도구
F(ω) = ∫ f(t) · e⁻ⁱωᵗ dt
Step 0 — 준비
오일러 공식 — 회전의 언어
복소 지수 함수는 단위원 위의 회전 운동과 일치한다
eiθ = cos θ + i·sin θ
→ cos θ : 실수축(x) — 좌우 진동
→ sin θ : 허수축(y) — 상하 진동
→ eiθ : 단위원 위의 점 — 파동 = 회전
→ e−iωt : ω 속도로 시계 방향 회전 (FT에서 사용)
Step 1 — 정의
Fourier Transform 공식
세 요소를 하나씩 쌓아올리면 완성된다
F(ω) = ∫ f(t) · e−iωt dt
F(ω) — 출력. 주파수 ω 성분의 강도
Step 2 — 첫 번째 요소
e−iωt — 회전자
신호를 ω 속도로 원에 감아올리는 동작
F(ω) = ∫ f(t) · e−iωt dt
오일러 공식에 −를 붙여 시계 방향으로 회전하는 함수
ω가 클수록 빠르게 회전 — 감기 주파수
t = 0 → 1일 때 정확히 ω/(2π) 번 완전 회전
이 함수 하나가 "원에 감기" 동작 전체를 수식으로 표현한 것
Step 3 — 두 번째 요소
f(t) · e−iωt — 신호를 회전에 올리기
원래 신호의 진폭을 회전자에 곱해 복소평면 위에 얹는다
F(ω) = ∫ f(t) · e−iωt dt
f(t)가 클수록 해당 순간의 점이 원점에서 멀어짐
신호의 봉우리는 감기는 방향에 따라 복소평면 위 한 방향에 쏠리거나 퍼짐
ω가 신호 주파수와 다르면 → 봉우리들이 사방으로 균등하게 퍼짐
ω가 신호 주파수와 같으면 → 봉우리들이 한 방향으로 정렬
Step 4 — 세 번째 요소
∫ dt — 전 시간에 걸친 평균
감긴 신호의 질량 중심을 계산하는 과정
F(ω) = ∫ f(t) · e−iωt dt
감긴 와이어 전체의 질량 중심(x좌표)을 구하는 과정
봉우리가 한 방향으로 몰릴수록 질량 중심이 원점에서 멀어짐
봉우리가 사방으로 퍼지면 질량 중심 ≈ 원점 → F(ω) ≈ 0
적분 = 평균 = 질량 중심 계산. 겁낼 것 없다.
Step 5 — 종합
완성된 공식 — 세 요소의 결합
각 기호가 하나의 물리적 동작과 1:1로 대응된다
F(ω) = ∫ f(t) · e−iωt dt
F(ω) 주파수 ω 성분의 강도 — 출력값
e−iωt ω 속도 시계 방향 회전자 — 원에 감기
f(t) · e−iωt 신호를 회전에 올려놓기 — 봉우리의 정렬 여부 결정
∫ dt 전 시간 평균 = 질량 중심 — 정렬 세기를 수치화
F(ω)가 크다 = ω 주파수 성분이 신호 안에 강하게 존재한다
