4-0

먼저: O( ) 표기법이란?

알고리즘의 속도를 비교할 때 입력 크기 N이 커질수록 연산 횟수가 얼마나 빠르게 늘어나는가를 나타내는 표기법이다. 정확한 연산 횟수보다 증가 패턴이 중요하다.

표기
직관적 의미
O(N)
N이 2배가 되면 연산도 2배. 선형 증가. 가장 이상적.
O(N log N)
N이 2배가 되면 연산은 약 2.x배. 선형에 가까운 준선형 증가.
O(N²)
N이 2배가 되면 연산은 4배. 제곱 증가. N이 클수록 폭발적으로 늘어난다.
▶ 직접 체험 — 성장 곡선 비교

슬라이더로 N의 최대값을 바꿔가며 세 가지 성장 곡선이 얼마나 다르게 벌어지는지 확인하세요.

O(N) O(N log N) O(N²)
💡
이렇게 읽으세요

N이 작을 때는 세 곡선의 차이가 작습니다. 슬라이더를 오른쪽으로 밀수록 O(N²)이 폭발적으로 커지는 반면 O(N log N)은 O(N)에 가까운 완만한 기울기를 유지합니다. FFT가 N log N으로 동작한다는 것이 왜 중요한지 한눈에 보입니다.

4-1

이산 푸리에 변환 (DFT) — 왜 N²인가?

DFT는 연속 적분을 N개 샘플의 합산으로 이산화한 버전이다.

ω_N = e−2πi/N (N차 단위근) — 앞서 본 e−2πift의 이산 버전. 복소 평면 단위원을 N등분하는 점들로, 같은 "회전하는 탐지기" 역할을 한다.

왜 N²인가 — 한 줄 설명

출력 X[0], X[1], …, X[N−1] → 총 N개
각 X[k]를 구하려면 입력 x[0]~x[N−1] N개 전부와 곱셈
연산 총합 = N개 × N번 = N²
▶ 직접 체험 — N에 따른 DFT 연산 횟수

N을 바꾸면 실제로 몇 번의 연산이 필요한지 확인하세요.

N = 64일 때 DFT는 4,096번 연산이 필요합니다. N을 오른쪽으로 밀면 연산 횟수가 제곱으로 늘어납니다.

4-2

고속 푸리에 변환 (FFT) — 왜 N log N인가?

FFT는 DFT와 수학적으로 완전히 동일한 결과를 낸다. 차이는 계산 방법이다. 단위근의 대칭성을 이용해 중복 계산을 제거하는 분할 정복 알고리즘이다.

핵심 아이디어 — 절반이 공짜

⚡

대칭성 — 한 번 계산으로 두 결과

E[k]: 짝수 인덱스 샘플의 DFT, O[k]: 홀수 인덱스 샘플의 DFT
두 식이 E[k]와 O[k]를 공유한다. 상위 N/2개만 계산하면 하위 N/2개는 부호만 바꿔 공짜로 얻는다.

왜 O(N log N)인가

분할 단계 수
log₂N 레벨
N개를 매번 절반으로 쪼개면
N → N/2 → N/4 → … → 1
단계 수 = log₂N
(N=8 → 3단계, N=1024 → 10단계)
각 레벨 작업량
레벨당 O(N)
각 레벨에서 N개의 원소를 한 번씩 처리

전체 = log₂N 레벨 × O(N)
= O(N log N)

📌

한 줄 요약

DFT: "모든 출력이 모든 입력을 각각 참조" → N×N = O(N²)
FFT: "절반씩 쪼아 재활용" → log₂N 레벨 × O(N) = O(N log N)

5

프로젝트와의 연결

여기까지 배운 개념이 프로젝트에서 어떻게 이어지는지 핵심만 정리한다.

5-1. 합성곱 정리 — FNO가 FFT를 쓰는 이유

신호에서 주파수를 분리하던 FFT가 PDE 공간장에도 그대로 적용된다. 연결 고리는 합성곱 정리다.

공간 전체에 걸친 합성곱(전역 상호작용) = 주파수 공간에서의 점별 곱셈.
O(N²)이 필요하던 전역 필터링이 FFT/IFFT 변환 비용을 포함해도 O(N log N)으로 줄어든다.

5-2. 모델 안에서의 분업

FFT (이 파트)
각 시각 t의 공간 스냅샷 u(x,t)를 주파수 모드 û(k,t)로 분해. PDE 해의 전역 공간 구조를 표현.
→
FNO Layer
학습 가능한 R(k)로 중요한 주파수 모드를 선택·필터링. IFFT로 공간 특징 복원.
→
SSM (시간)
FNO가 추출한 공간 특징이 시간에 따라 어떻게 진화하는지 Attention 없이 학습.
⚡

Attention-free가 가능한 이유

Attention은 모든 위치 쌍 (i, j)를 비교해 전역 구조를 발견한다 → O(N²).
FNO는 FFT가 처음부터 물리적으로 올바른 기저(푸리에 모드)를 제공하기 때문에, 이 조회 과정이 불필요하다. 합성곱 정리로 전역 상호작용을 O(N log N)에 처리하는 것이 이 프로젝트의 핵심 설계 근거다.
